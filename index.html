Method & Data Provenance

This is a 0–3 hour thunderstorm nowcast-style guidance product. It samples 49 forecast points (selected point + 16 bearings × 20/35/50 km) around the selected coordinate. Each point is scored hour-by-hour over the next three hours using weather code, precipitation probability, CAPE, lifted index, convective inhibition, precipitation/showers, humidity, cloud structure and low/mid/high-level steering winds. The displayed direction and range identify the strongest persistent spatial convective hotspot within the next three hours; they are model guidance, not a deterministic storm-cell track. For operational nowcasting, compare this field with current radar, satellite and lightning observations, especially when convective cells are already present. The spatial forecast is based on the GFS endpoint used elsewhere in this page, with the same selected coordinate as the main forecast.
